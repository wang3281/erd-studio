# Code of Conduct

We adopt the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) for all project spaces and community interactions.

Examples of unacceptable behavior include harassment, discriminatory language, deliberate intimidation, publishing another person's private information, and sustained disruption. Maintainers may remove, edit, or reject contributions and may temporarily or permanently restrict participation when behavior is inappropriate, threatening, or harmful.

Report conduct concerns privately to the repository owner through the contact method shown on the `@wang3281` GitHub profile. Reports will be reviewed promptly and kept confidential to the extent practical.
